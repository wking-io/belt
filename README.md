# Belt

Belt is a dev-only package family for adding explicitly registered tools to applications through a shared in-app toolbar surface.

The repository is currently private-package scaffolding while the public package names and product identity settle.

## Backend v1

See [docs/backend-v1-usage.md](docs/backend-v1-usage.md) for the current backend API usage guide, including `toolbar.config.ts`, the `/__toolbar` protocol, Remix and Vite mounting, and the Iterations backend.

## Tools

See [docs/tools.md](docs/tools.md) for Tool Registration, Tool Definition, ready-made React Tool composition, and the split between Toolbar API runtime data and local renderer config.

## Renderers

See [docs/remix-renderer.md](docs/remix-renderer.md) for the Remix UI renderer and [docs/react-renderer.md](docs/react-renderer.md) for the React glyph renderer.
